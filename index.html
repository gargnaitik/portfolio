    Kanakam

    A jewellery store whose prices track the live gold rate, per karat.

    • A background job derives per-karat rates from one API call (cached in Redis) and reprices the catalogue via MongoDB bulkWrite. Checkout reuses the same pricing function, so displayed and charged prices always match.
    • Polyglot data layer: PostgreSQL transactions for orders and payments, MongoDB for the catalogue, with atomic conditional stock reservation and compensating rollback to prevent overselling.
    • Server-side HMAC-SHA256 Razorpay verification bound to order and user; JWT, bcrypt (12 rounds), SHA-256-hashed email tokens (24h TTL), Redis OTPs, rate limiting and token blacklisting.
    • 35 Jest/Supertest tests with GitHub Actions CI covering pricing, payments, stock reservation and auth.
