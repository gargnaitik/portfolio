# Naitik Garg — Portfolio

A single-file static site. No build step, no dependencies (fonts load from Google Fonts).

## Run locally
Open `index.html` in any browser.

## Deploy
- **GitHub Pages:** push this folder to a repo (e.g. `gargnaitik.github.io`), then Settings → Pages → deploy from the `main` branch.
- **Netlify / Vercel:** drag and drop this folder onto the dashboard.

## Before publishing
Replace the placeholder links in `index.html` (search for `github.com/gargnaitik` and `linkedin.com/search`):
- DocSense AI GitHub repo and Live Demo URL
- ML Challenge 2026 GitHub repo
- Kanakam GitHub repo
- LinkedIn profile URL
